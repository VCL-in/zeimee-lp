## 採用した変更

独立した参考資料欄がある10002〜10026の25記事へ `ColumnReferences` を適用した。主要な出典は本文の論点に合わせて選び、短い資料名・発行元・用途を示す。全出典の正式名・URL・参照条文・発行日・版・施行日・確認範囲は詳細一覧へ保持する。10001は各サービス欄に出典を表示する既存構成を維持する。

## 出典と日付の扱い

- 共通の確認日は2026-10-10。詳細一覧では同じ確認日の繰り返しだけを省く。データ中の元の `meta` は保持し、表示用の `formatReferenceMeta` で整える。
- 10004のChatGPT・Claude資料の2026-10-11確認は個別に維持し、共通日と対象範囲を区別する。
- 10017の「2026年10月10日確認の掲載版」は、表示上は共通確認日に対応する「確認時点の掲載版」とする。元のデータは保持する。
- 「案」「会員専用」「本文未確認」、現行版・未施行・将来施行などの条件を維持する。確認できていない本文を主要な主張の根拠には選ばない。
- 他社サービスへの外部リンクを設けない既存方針を維持し、外部URLを新しく作らない。
- 本文、編集方針、記事メタデータ・日時、記事末尾のZeimee案内は変更しない。
